One-page takeaway

A function is a machine

One input, exactly one output. Arrows (mapping) and dots (graph) are two drawings of the same thing.

Ask what a change in x does

Add to x? Multiply x? The steady answer is the fingerprint, and the fingerprint gives the shape.

Four fingerprints

Line: add → add. Power: multiply → multiply. Exp: add → multiply. Log: multiply → add.

Long run: log, power, exp

Exp eventually beats any power, and any power beats log. “Eventually” can be late.

A matrix is a function

Its columns are where the unit arrows land; det is the area factor. The a in ax is a 1×1 matrix.

Up close, it’s all linear

Zoom into a smooth curve and it becomes a line. Its slope, the derivative, is the local stretch.

Function Sense · 21　　Real numbers throughout; “up close it’s linear” needs a smooth function.

Back to the original question: how do I get a sense for functions, and how does “mapping” in linear algebra relate to them? First, function and mapping are the same idea: a rule that sends each input to exactly one output. A graph is just that mapping drawn with the output axis standing up. Second, don’t memorize shapes; learn fingerprints. Ask what adding to x or multiplying x does to the output. Lines turn adding into adding, powers turn multiplying into multiplying, exponentials turn adding into multiplying, and logs turn multiplying into adding. Third, in linear algebra the inputs become vectors and a matrix is a well-behaved function that keeps grid lines straight; ax is its one-dimensional case, and ax + b is linear-plus-shift, called affine. Finally, the link between curves and matrices: any smooth function, zoomed in, looks like a linear map. In one dimension that is the slope, in more dimensions the Jacobian matrix.
