16 · Honest limits

Where these intuitions break

Corners and jumps

The absolute value |x| has a corner at 0; a step function jumps. Zooming in never makes those look straight, so “locally linear” needs a smooth function.

Not every input is allowed

Log only accepts positive x. With real numbers, the square root rejects negative x, and 1/x breaks at 0. Always ask: which inputs make sense?

“Eventually” can be very late

x¹⁰ stays ahead of 2ˣ until x ≈ 58.8. Over a short range the ranking of families can flip, so check actual numbers.

Some maps can’t be undone

x² sends 2 and −2 to the same place. A matrix with det = 0 squashes the plane onto a line. Neither has an inverse.

Function Sense · 20

Every intuition here has edges. Locally linear only works for smooth functions; a corner like |x| at 0 stays a corner however far you zoom in. Logs and square roots only accept some inputs when we stay in the real numbers. Growth-rate rankings are about the long run; x to the 10 beats 2 to the x for all x between about 1.08 and 58.8. And inverses only exist when no information is lost: x squared merges 2 and −2, and a matrix with determinant 0 merges whole lines of points, so neither can be undone without extra information (for x squared we can undo it if we agree to keep only x ≥ 0, which is the square root).
