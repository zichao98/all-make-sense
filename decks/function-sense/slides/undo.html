18 · When can you undo it?

Not a bijection? Shrink it until it is

Undo = run every arrow backwards. That needs a perfect pairing.

Squaring

Keep only x ≥ 0

Throwing away the negative inputs removes the collisions. The backwards map is the square root.

Doubling

Target: positive numbers

Naming only the positives as outputs removes the misses. The backwards map is log.

Matrices

Need det ≠ 0

Then nothing gets squashed, every point comes from exactly one point, and A⁻¹ exists.

Do the map, then its inverse, and you are back where you started. Arcsin is built the same way: sin restricted to −90° to 90°.

Function Sense · 23

An inverse function runs every arrow backwards, so it only exists for a bijection. When a function is not one, the standard trick is to shrink the inputs or the target until it is. Squaring is not one-to-one on all real numbers because 2 and −2 collide; keep only x ≥ 0 and the collisions disappear, and the backwards map is the square root. 2 to the x is not onto all real numbers because it never outputs 0 or a negative; name only the positive numbers as the target, and the backwards map is log base 2. A square matrix with nonzero determinant is already a bijection of the plane, and its inverse is the inverse matrix. Arcsin is defined the same way: sine restricted to angles from −90 to 90 degrees is a bijection onto −1 to 1. In every case, doing the map and then its inverse returns the original input.
