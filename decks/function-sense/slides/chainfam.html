Eye estimate: when the middle matches, only the two ends matter

Add in, multiply out: exponential-like. Multiply in, add out: log-like. If the middle doesn’t match (exp, then exp), you get something new that outgrows every exponential.

Function Sense · 22

The fingerprints from Part Two compose nicely. Write each machine as what it does to adding and multiplying, then follow the chain. A line after a line is still a line, and the slopes multiply. A power of a power is a power, and the exponents multiply. A line followed by an exponential is still an exponential: 2 to the (ax + b) equals 2 to the b times (2 to the a) to the x, so the base becomes 2 to the a. A power followed by a log is still a log: log of x to the n is n log x. And an exponential followed by a log turns add-into-multiply-into-add, which is add-into-add, a line; with matching bases it is exactly x. The rule of thumb: when each machine's output kind matches the next machine's input kind, as in every row here, only the input side of the first machine and the output side of the last machine decide the family of the result. When they don't match, the result is something new: an exponential of an exponential, 2 to the (2 to the x), grows faster than any plain exponential.
