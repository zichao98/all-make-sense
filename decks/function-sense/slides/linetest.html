Function Sense · 22

On a graph, a horizontal line at height c picks out every input whose output is c. So counting where it crosses the curve answers both questions at once. If some horizontal line crosses twice, two inputs share an output: not one-to-one. If some horizontal line never crosses, that output is missed: not onto. The animation sweeps the blue line and counts the hits. x squared fails both: lines above 0 hit twice and lines below 0 miss. x cubed always hits exactly once. 2 to the x never hits twice, but every line at 0 or below misses. x cubed minus 3x is the opposite: every line hits at least once, but lines between −2 and 2 hit three times, because the curve turns around at x = −1 (height 2) and x = 1 (height −2).
