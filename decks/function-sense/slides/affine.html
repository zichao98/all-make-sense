Function Sense · 17

You said that from the linear-algebra point of view, ax + b is linear. That is almost right, and the gap is worth knowing. In linear algebra, a map is linear when two rules hold: mapping a sum gives the sum of the mapped parts, and mapping a scaled input gives the scaled output. A consequence is that 0 must map to 0. f(x) = ax passes. f(x) = ax + b fails as soon as b is not 0, because 0 goes to b. Mathematicians call ax + b affine: a linear map followed by a shift. In school, people call any straight-line function linear, so the two fields use the word differently. The general version in any dimension is x goes to Ax + b: first a matrix, then a shift. Neural network layers are exactly this, followed by a nonlinearity.
