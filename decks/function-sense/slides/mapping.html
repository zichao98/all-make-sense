Part Three

Function = mapping

Same idea, two names. “Map” just stresses that points move.

In linear algebra a matrix is a function: a vector goes in, a vector comes out. The number a in ax is the smallest matrix there is.

Now to the linear-algebra question: if a matrix is called a mapping, and ax + b is a function, how are they related? Short answer: they are the same concept. A function or map is any rule that sends each input to exactly one output. In school the inputs are numbers; in linear algebra the inputs are vectors, points in the plane or in space. A matrix is a special, very well-behaved kind of function on vectors.
