04 · Curves

Curves stretch the line unevenly

Feed in evenly spaced inputs: 0, 0.5, 1, … , 4. Then look at the gaps between the outputs.

Function

Gaps between outputs

all equal: 2, 2, 2, …

growing: 0.25, 0.75, 1.25, … , 3.75

each one 1.41 times the one before

A curve has a different stretch factor at every spot. That is the whole difference between linear and nonlinear.

Keep this in mind: later we zoom in on a tiny piece of a curve, and the stretch there is constant again.

Function Sense · 06

Same experiment as before, but with curves. Nine evenly spaced inputs from 0 to 4 go in. With 4x, the outputs are evenly spaced too, every gap is 2. With x squared, the gaps grow steadily: 0.25, 0.75, 1.25 and so on up to 3.75, growing by 0.5 each time. With 2 to the x, each gap is the square root of 2, about 1.41, times the previous one, so they grow faster and faster. In other words, a curve stretches different parts of the number line by different amounts. A line stretches every part equally. Keep that picture; it is what makes linear algebra and calculus click later.
