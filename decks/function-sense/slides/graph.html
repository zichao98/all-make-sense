02 · Reading a graph

A graph is the same mapping, drawn flat

Take the arrow picture and stand the output line upright.

Floor: inputs run along the x-axis

Wall: outputs run up the y-axis

Dot: each arrow becomes one point (x, f(x))

To read a graph, pick an x, walk up to the curve, and read off the height. That height is f(x).

Steep means a small step in x moves the output a lot. Flat means the output barely moves.

Function Sense · 03

This slide connects the two pictures you have probably seen separately. Start with the mapping view: inputs on one line, outputs on another, arrows between them. Now slide the input line down to become the floor, and rotate the output line so it stands up as the wall. Every arrow from x to f(x) collapses into a single dot sitting above x at height f(x). Join all the dots and you get the curve. So a graph is not a mysterious shape; it is a table of input–output pairs, drawn as dots. Steepness is the most useful thing to read: steep means sensitive, flat means insensitive.
