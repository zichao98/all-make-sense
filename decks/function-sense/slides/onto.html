16 · One-to-one and onto

Collisions and misses sort every mapping

One-to-one (injective): different inputs always give different outputs. No collisions.

Onto (surjective): every output in the target set gets hit. Nothing missed.

Both (bijective): a perfect pairing between inputs and outputs.

Only a bijection can be run backwards: each output points back to exactly one input.

“Onto” depends on the target you name: 2ˣ is onto the positive numbers, but not onto all real numbers.

Function Sense · 21

The animation shows the four possible combinations with small sets so you can count the arrows. Each case has the same rule as any function: every input on the left sends out exactly one arrow. What changes is what happens on the right. A collision, circled in orange, is an output with two or more arrows landing on it; that breaks one-to-one. A miss, circled in blue, is an output nobody lands on; that breaks onto. In the last case every output gets exactly one arrow, so you can reverse all of them and get another function: the inverse. One subtlety: whether a map is onto depends on which set you call the outputs. 2 to the x never produces 0 or negative numbers, so it is onto the positive numbers but not onto all real numbers.
