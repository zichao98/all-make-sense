Part Four

Kinds of mappings

Two questions about the arrows: do any collide? Is any output missed?

No collisions is called one-to-one. Nothing missed is called onto. Both together means you can run the arrows backwards, which is exactly when an inverse exists.

Every function sends each input to exactly one output, but functions still differ in how their arrows land. Two questions sort them. First: can two different inputs land on the same output? If never, the map is one-to-one, also called injective. Second: does every possible output get hit by some arrow? If yes, the map is onto, also called surjective. A map that is both is a bijection: a perfect pairing between inputs and outputs. These are the standard mapping types in every linear algebra and analysis course, and they decide whether you can undo a function.
