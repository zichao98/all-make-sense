14 · Nonlinear maps

Nonlinear maps bend the grid

A nonlinear map also sends every point somewhere, but now the grid lines curve.

Linear map: the same stretch everywhere, one matrix for the whole plane

Nonlinear map: a different stretch at every spot

Zoom into one small patch (the orange box) and the bending fades away. Up close, the map acts like a matrix.

This is the 2D version of the next slide. The matrix you see up close is called the Jacobian.

Function Sense · 18　　Map shown: x moves by 0.35 sin(1.3y), y moves by 0.35 sin(1.3x).

This is the two-dimensional version of Part One’s “curves stretch unevenly”. The map in the animation pushes each point a little sideways and a little up, by an amount that depends on where it is, so the grid lines bend. But look at the inset: it shows the small orange box magnified ten times, and there the grid lines are nearly straight and evenly spaced again. In other words, a smooth nonlinear map looks like a matrix when you zoom in far enough. That local matrix is called the Jacobian. It is different at every point, which is exactly what makes the map nonlinear overall.
