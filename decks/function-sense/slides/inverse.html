08 · Undo

Log undoes exp: the same curve, mirrored

Exp goes from “number of steps” to “size”. Log goes from size back to the number of steps.

Undoing a function swaps input and output. Swapping x and y on a graph means mirroring it across the line y = x.

Exp: creeps toward 0 on the left, explodes on the right

Log: only for positive x; climbs forever, slowly

Same story for x² and √x when x ≥ 0: mirror images.

Function Sense · 11

Exponentials and logarithms are inverses: each one undoes the other. 2 to the x turns a number of doublings into a size; log base 2 turns a size back into the number of doublings. Undoing a function means swapping the roles of input and output. On a graph, swapping x and y is the same as reflecting across the diagonal line y = x. The animation moves an orange dot along 2 to the x and shows its partner on log base 2 of x: the two coordinates are simply swapped, and the dashed segment between them always crosses the mirror line at a right angle. This also explains the shapes: because 2 to the x never reaches 0 or goes negative, log is only defined for positive x.
