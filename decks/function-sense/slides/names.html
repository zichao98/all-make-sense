11 · One idea, several names

Function, map, transformation: one idea

Every element of X gets exactly one partner in Y. X can be numbers, vectors, anything.

The a in ax is a 1×1 matrix: a function that stretches the number line.

A 2×2 matrix is a function that sends each point of the plane to another point.

WordWhat it stressesTypical example
FunctionThe rule that turns an input into an output“square the number”
Map, mappingWhere each point gets sent (the arrows)“send each point to its double”

Function Sense · 15

The vocabulary is the confusing part, not the idea. Function, map, mapping and transformation all mean: a rule that assigns each input exactly one output. The words just put the spotlight in different places. “Function” stresses the rule or formula. “Map” stresses where each point gets sent, the arrows. “Transformation” stresses the whole space moving at once, usually onto itself. A linear map is the special case that keeps straight lines straight and keeps 0 fixed, and every linear map between ordinary vector spaces can be written as a matrix. In one dimension the matrix is a single number a, so f(x) = ax is the simplest linear map of all.
