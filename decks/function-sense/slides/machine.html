01 · What a function is

A function is a machine: one in, one out

Input: you hand it a number x

Rule: it decides where that number goes

Output: exactly one number comes back

“Function” and “mapping” are two names for the same thing. “Mapping” just pictures the arrows from inputs to outputs.

Two inputs may share an output: x² sends −2 and 2 to 4. One input may never have two outputs.

Function Sense · 02

A function is a rule that takes one input and returns exactly one output. The animation draws it as a mapping: two number lines, inputs on top, outputs at the bottom, and an arrow from each input to where it lands. It cycles through three rules. For 2x, evenly spaced inputs stay evenly spaced, only farther apart. For x squared, −2 and 2 land on the same spot, which is fine. For x + 3, everything just slides. The one forbidden thing is one input with two arrows coming out of it. That is the entire definition.
