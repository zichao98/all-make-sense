Engineering Math Sense · 22　　GB = 10⁹ bytes. Activations grow with batch size and sequence length and come on top.

Training memory starts with simple arithmetic. In plain float32 with the Adam optimizer, each parameter needs its weight (4 bytes), its gradient (4 bytes) and Adam's two running moments (8 bytes): 16 bytes. A model with one billion parameters therefore needs 16 GB before storing a single activation, and seven billion parameters need 112 GB. Mixed precision and optimizer tricks change the constants but not the habit: multiply parameters by bytes per parameter first. Linear algebra also offers a way out. A 4096 by 4096 weight matrix has 16,777,216 entries. If the change you need is approximately low rank, you can write it as A times B transposed with A and B each 4096 by 8, which is 65,536 numbers, 0.39 percent of the full matrix. Low-rank adaptation methods such as LoRA fine-tune large models this way.
