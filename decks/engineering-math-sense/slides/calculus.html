Backprop multiplies local slopes

Each node only knows its own slope. Backprop multiplies them from the loss back to every weight.

Why it scales: one backward pass costs a small multiple of one forward pass, for 10 weights or 10 billion.

A gradient is a direction, not a destination

−∇L points downhill from where you stand. How far to step is the optimizer’s job.

Engineering Math Sense · 11

loss.backward() is the chain rule applied mechanically. The animation uses the smallest possible graph: x = 1.5, weight w = 0.8, bias b = −0.2, target t = 2, and loss L = (y − t)². Forward: wx = 1.2, y = 1.0, L = 1.0. Backward, starting from ∂L/∂L = 1: the square node has local slope 2(y − t) = −2. The plus node passes the gradient through unchanged to both wx and b, so ∂L/∂b = −2. The multiply node scales it by x, so ∂L/∂w = −2 × 1.5 = −3. Then the update with learning rate 0.1 gives w = 1.10 and b = 0.00, and the loss drops to 0.1225, then 0.015 on the next iteration. Each node needed only its own local derivative. That is why reverse-mode differentiation is cheap: the cost of all the gradients is a small constant multiple of the cost of the forward pass, no matter how many parameters there are.
