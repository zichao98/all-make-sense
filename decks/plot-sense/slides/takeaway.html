Plot Sense · 24

Back to the question you started with: how do you choose a plot, and how does each one bring out information? Start from the question, not the chart type. Each plot maps columns to visual channels, and position on a shared axis is the most precise channel, so give it to the comparison that matters. Always plot before trusting a summary, because identical statistics can hide different stories. For one variable, histograms show shape but depend on bin width, box plots summarize but hide shape, and log axes tame skew. For comparisons, bars must start at zero, pies only work for a few parts, and means need intervals. For relationships, scatter plots show association, r squared tells you how much, and density plots handle big data. For time series, smoothing trades noise for lag, log axes make growth rates visible, and two y-axes invent relationships.
