01 · What a plot is

A plot maps columns to channels

A table has rows and columns. A plot turns each row into one mark and each column into one visual channel.

x position ← a number column (price)

y position ← another number column (sales)

color ← a category column (channel)

Choosing a chart = choosing the channels

Give the comparison that matters most the best channel: position along a shared axis.

Plot Sense · 02　　Example data, invented for illustration.

Before any chart type, there is one idea. Every plot is a mapping from columns of a table to visual channels. In the animation, each row of a small example table, six items with a price, a sales figure and a sales channel, flies into the scatter plot as one dot. Price becomes horizontal position, sales becomes vertical position, and the channel becomes color. A bar chart maps a category to position and a number to length. A heatmap maps two categories to position and a number to color. Once you see charts this way, choosing one is no longer about names. It is about deciding which column deserves the best channel. The table here is invented for illustration.
