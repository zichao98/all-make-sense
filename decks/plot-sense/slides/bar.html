Eye rule: need to zoom in? Switch to dots

Dot plots and line charts may start anywhere, because position, not length, carries the value.

Plot Sense · 11　　Visual ratio = (52 − baseline) / (50 − baseline): 1.04 from zero, 3 from 49.

A bar encodes its value as length from the baseline, so the reader compares lengths. Take two values, 50 and 52. With a zero baseline, bar B is 52/50 = 1.04 times as tall as bar A, which matches the truth. Start the axis at 49 and the visible lengths become 1 and 3, so B looks three times as tall: a 4 percent difference drawn as 200 percent. Spreadsheet defaults sometimes do this automatically. If you need to zoom in on small differences, change the mark instead: a dot plot or a line encodes the value as position, which carries no promise about length, so the axis can start wherever the data are. Also sort bars by value unless the categories have a natural order; sorting makes the ranking readable without effort.
