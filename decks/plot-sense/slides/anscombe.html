Eye rule: plot before you summarize

Means and correlations compress the data. The plot shows what they threw away.

Plot Sense · 05　　Anscombe, “Graphs in Statistical Analysis” (1973). Statistics recomputed for this deck.

Francis Anscombe built these four small datasets in 1973 to make one point. Each has 11 points. All four have the same mean of x, 9.00, the same mean of y, 7.50, the same variances, the same correlation, 0.816, and the same least-squares line, y = 3.00 + 0.500x. These values were recomputed for this slide. But the plots tell four different stories. Set I is a noisy straight line. Set II is a smooth curve, so a straight line is the wrong model. Set III is a perfect line with one outlier that drags the fit. Set IV has ten points at the same x and one far point that alone decides the slope. The summary is identical; the conclusions are not. This is the strongest argument for plotting first.
