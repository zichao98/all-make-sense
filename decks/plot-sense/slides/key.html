So the useful question changes

“Which chart should I use?”
= “What am I asking?”

How is it distributed? Which is bigger? Do they move together? Where is it heading? Each question has a chart that answers it best.

This is the reframing the rest of the deck builds on. People usually start from the chart type they know. It works better to start from the question. How is one variable spread out: histogram, box plot. Which category is bigger, and by how much: bar or dot plot. Do two variables move together: scatter plot. How does something change over time: line chart, often with smoothing or a log axis. Each part of the deck takes one of these questions, shows the chart that answers it, and shows what that chart can hide.
