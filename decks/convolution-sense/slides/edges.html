08 · What a kernel looks for

A 3×3 kernel is a tiny pattern detector

p = the 9 pixels under the window

Each output is one fold, now in the 9-D space of patches. Patches on the bright side of the hyperplane light up.

KernelLights up on
Vertical edgeDark → bright, left to right
Horizontal edgeDark → bright, downward
LaplacianCreases: the 2D (1, −2, 1)

Trained networks learn their own kernels; early layers often end up with edge-like ones.

Convolution Sense · 11

In 2D, a 3×3 kernel computes w·p + b, where p is the 9 pixel values under the window. That is a dense neuron on a 9-dimensional input, the patch. Its fold is a hyperplane in patch space, and patches on the positive side make the output light up. The animation computes three hand-picked kernels live. The vertical-edge kernel (−1 0 1 in each row, weighted 1, 2, 1) responds where brightness increases from left to right, so it lights the left edges of the bright shapes; ReLU clips the right edges. The horizontal version does the same top to bottom. The third input is the height map of a one-layer ReLU network with 3 creases, like the 2D slides in the first deck. The Laplacian kernel, 0 1 0 / 1 −4 1 / 0 1 0, is the 2D version of (1, −2, 1). On every flat facet it gives exactly 0, and it lights up only along the creases. All 3 creases fold upward here, so ReLU keeps them all. In a trained network nobody hand-picks the kernels; first-layer kernels are often observed to look edge-like, but that is an empirical tendency, not a rule.
