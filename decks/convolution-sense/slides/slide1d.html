02 · Convolution in 1D

Slide one small neuron along the input

Kernel: k = 3 weights, here (−1, 0, 1). Every output reuses the same three.

Positions:

9 − 3 + 1 = 7 outputs

This kernel subtracts each value from the one two steps ahead. It lights up where the signal rises.

Convolution Sense · 04

Start in one dimension. The input is 9 numbers that rise from 0 to 3, stay flat, then fall back. The kernel has k = 3 weights, (−1, 0, 1). At each position the neuron multiplies the 3 numbers under the window by the 3 weights, adds them up, and applies ReLU. Then the window moves one step right. That is the whole operation. Machine learning libraries compute this “cross-correlation” form, without flipping the kernel, and still call it convolution. Count the positions: the window fits at 9 − 3 + 1 = 7 places, so there are 7 outputs. The sums are 2, 2, 1, 0, −1, −2, −2; after ReLU they are 2, 2, 1, 0, 0, 0, 0. The kernel works as a slope detector: positive where the input rises and clipped to zero elsewhere. Each output is still one ordinary neuron with one fold. It just looks through a 3-wide window, and all 7 copies share the same weights.
