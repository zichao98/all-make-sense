Convolution Sense · 14

Dumoulin and Visin count output size as the number of places the kernel fits. Without padding the kernel starts at the left edge and slides until it touches the right edge: i − k steps plus the starting position, so o = i − k + 1. Zero padding adds p cells on each side, so the effective input is i + 2p and o = (i − k) + 2p + 1. The animation cycles through the paper's four examples. With i = 4, k = 3 and no padding, the output is 2×2. With i = 5, k = 4, p = 2, it is 6×6, larger than the input. Half or “same” padding uses p = 1 for a 3×3 kernel, more generally the floor of k/2 for odd k, and keeps the output equal to the input, 5×5. Full padding uses p = k − 1 = 2, so every partial overlap counts and the output is 7×7. Each row of the table was recomputed from the formula.
