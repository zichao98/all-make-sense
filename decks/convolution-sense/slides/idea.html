So the question changes

“Is this pattern anywhere?”
= “Slide one small neuron.”

That is a convolution. Two choices make it: each copy sees only a small window (locality), and every copy uses the same weights (sharing).

This is the turning point of the deck. A dense neuron asks “is this pattern at this exact spot?”. For images and sound we usually want “is this pattern anywhere?”. The answer is to take one neuron with a small weight vector, say 3 numbers in 1D or 3×3 numbers in 2D, and evaluate it at every position. Dumoulin and Visin describe a discrete convolution in exactly these terms: a linear map that is sparse, because only a few inputs feed each output, and that reuses parameters, because the same weights apply at many locations. Each copy is still an ordinary ReLU neuron with its own fold. The rest of the deck builds on that.
