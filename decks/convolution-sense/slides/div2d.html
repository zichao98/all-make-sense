Part Two

Into 2D images

The window becomes 3×3. The fold now lives in patch space.

We follow the worked example from Dumoulin and Visin's guide, then write the convolution as a matrix. That shows exactly how it relates to the dense layers from before.

Images have two ordered axes, height and width, so the kernel becomes a small square. Nothing else changes: each output is still one neuron applied to one window, and all windows share the same weights. This part uses the numerical example from “A guide to convolution arithmetic for deep learning” by Vincent Dumoulin and Francesco Visin, then rewrites the operation as a sparse matrix. The matrix view connects back to hyperplanes: every row is one neuron's fold.
