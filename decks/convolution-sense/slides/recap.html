01 · Where we left off

A dense neuron watches one fixed spot

One neuron = one fold. On a 28×28 image, x has 784 numbers, so w has 784 weights: one hyperplane in 784 dimensions.

The catch: each weight is tied to one pixel. The neuron learns “a ring right here”, not “a ring”.

Move the pattern and it goes dark

A dense layer would need a separate neuron for every place the ring might appear.

Convolution Sense · 02

Recall the earlier deck: one ReLU neuron computes ReLU(w·x + b), a fold along the hyperplane w·x + b = 0. For an image, x is every pixel, so each weight is welded to one pixel position. In the animation, the dense neuron's weights (orange, middle) were set to match a ring at the center. Its response is ReLU of the overlap minus half the ring's size, scaled so a perfect match gives 1. When the ring sits exactly there, it fires at 1. Shift the ring a few pixels and the overlap falls below half, so the output drops to 0. The orange bar uses the same 7×7 ring as a small kernel, checked at every position, and keeps the best response. Wherever the ring goes, some position matches it perfectly, so that bar stays at 1. That small, shared, everywhere-checked neuron is a convolution.
