14 · Going back up

Transposed convolution runs C backwards

C maps 16 → 4. Its transpose maps 4 → 16 along the same connections: a way back up, used in decoders and upsampling.

As a convolution: pad with k − 1 zeros.

For stride s: put s − 1 zeros between inputs.

The shape comes back, not the values

It is not an inverse, which is why the guide avoids the name “deconvolution”.

Convolution Sense · 18

Recall the matrix view: a 3×3 kernel on a 4×4 input is a 4×16 matrix C that maps 16 numbers to 4. Its transpose maps 4 numbers back to 16 and connects the same pairs of positions. That operation is called a transposed convolution. The guide shows it can always be computed as an ordinary convolution on a modified input. For the stride-1 case, pad the 2×2 map with k − 1 = 2 zeros on every side and slide the same-sized kernel: the output is 2 + 2 = 4 per axis, so 4×4. For a stride-2 convolution, such as i = 5, k = 3, s = 2, first insert s − 1 = 1 zero between neighbouring inputs. That stretches 2 to 3, and padding 2 makes it 7, giving o′ = 2·(2 − 1) + 3 − 0 = 5. This is why it is also called fractionally strided convolution. When several input sizes share an output size, as 5 and 6 did with stride 2, the guide adds extra zeros at the bottom and right edges to pick the right one. A transposed convolution restores the shape, not the original values. It is not the mathematical inverse, so the guide argues against calling it deconvolution.
