09 · Many kernels, many channels

Many kernels give many channels

Step 1

One kernel, one map

Slide a 3×3 kernel over the image and you get one feature map: one pattern, checked everywhere.

Step 2

n kernels, n maps

Each kernel learns its own pattern. The stack of n maps is the next layer's input, with n channels.

Step 3

Kernels span all channels

With m input maps, each kernel is m × k × k. The paper's 2 → 3 map example uses 3 × 2 × 3 × 3 = 54 weights.

At one position, a conv layer is a dense layer on the patch

n neurons, each folding the m·k·k numbers under the window. Then the same n neurons run at every other position.

Convolution Sense · 12

One kernel finds one kind of pattern. A real layer uses many, say n kernels, and produces n feature maps, often called channels. The next layer then sees an input with n channels. A kernel there is no longer a flat 3×3 square: it is a small block, m × k × k, covering every input channel at once. Dumoulin and Visin show 2 input maps turned into 3 output maps with a 3 × 2 × 3 × 3 collection of kernels, which is 54 weights. At one position, the layer takes the m·k·k numbers under the window and applies n ordinary neurons: a dense layer with n folds in an m·k²-dimensional patch space. Convolution then reuses those same n neurons at every position.
