06 · Convolution as a matrix

A convolution is a dense layer with tied weights

Flatten the 4×4 input to 16 numbers and the 2×2 output to 4. C is 4×16.

Each row is one neuron: one hyperplane in 16 dimensions, like any dense neuron.

But the rows are tied: each holds the same 9 weights, shifted, plus 7 zeros.

Convolution Sense · 09

Dumoulin and Visin make this point with a 4×4 input and a 3×3 kernel, which gives a 2×2 output. Number the 16 input pixels row by row, and the 4 outputs the same way. Then the convolution is an ordinary matrix product y = Cx, with C of size 4×16. Look at one row. It is a dense neuron's weight vector over all 16 pixels, so it defines one hyperplane in 16-dimensional space, like the neurons from the first deck. What makes it a convolution is the pattern: each row contains the same 9 kernel weights, placed on the pixels under its window, and zeros everywhere else. A dense layer from 16 to 4 has 64 free weights; this layer has only 9. The matrix view also gives the backward pass: gradients flow through C transposed. We will use C transposed again for transposed convolutions.
