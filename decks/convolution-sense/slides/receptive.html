Convolution Sense · 17

A single 3-wide kernel sees 3 inputs. Stack another 3-wide layer on top and each top unit sees 3 units below, which together cover 5 inputs. With plain kernels every layer adds 2, so L layers see 2L + 1 inputs: 3, 5, 7, 9. That is slow. Dilation spreads the taps apart, with d − 1 gaps between them. The guide gives the effective kernel size as k + (k − 1)(d − 1) and the output size as floor((i + 2p − k − (k − 1)(d − 1))/s) + 1. If the dilations double from layer to layer, 1, 2, 4, 8, the receptive field becomes 3, 7, 15, 31: 2^(L+1) − 1, roughly doubling each layer with no extra weights. This is the same doubling the first deck found when depth folded a sawtooth onto itself. Stride and pooling widen the view in a similar way. The animation traces the inputs that can reach the top unit; with dilation the 31 inputs are covered exactly once, with no gaps.
