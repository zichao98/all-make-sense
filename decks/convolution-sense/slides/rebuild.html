04 · Run it backwards

Spikes convolved with a ramp rebuild the line

Spikes: where each kink sits and how hard it bends. Ramp: one shared ReLU shape.

Every neuron is the same ramp, shifted and scaled. Sliding one shape to many places is a convolution.

A conv layer swaps what is learned

ReLU layer: fixed shape, learned positions. Conv layer: fixed positions (every grid point), learned shape.

Convolution Sense · 06

Now run the previous slide backwards. Take the 4 spikes, at positions 4, 9, 13.5 and 17 with heights 0.6, −1.1, 0.9 and −0.7. Put a copy of one ramp shape, ReLU(x), at each spike, scaled by its height, and add them up. The result is exactly the blue line we started from. Written as a formula, the sum of a_i times ReLU(x − k_i) equals the spike train convolved with ReLU. So a one-layer ReLU network in 1D is already a convolution: one fixed shape slid to learned places. One honest caveat: a neuron with a negative weight w faces left. ReLU(k − x) equals ReLU(x − k) minus (x − k), so it is the same ramp plus a straight line, and the picture still holds with one extra line added. A convolutional layer turns this around. Positions are no longer learned, because the kernel sits at every grid point. Instead the shape, the kernel weights, is what training adjusts.
