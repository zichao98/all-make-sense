Deep Learning Intuition · 06

Both rows on the right use the same number of neurons. The top row spaces kinks evenly; the bottom row distributes them using the square root of the curvature, packing more near the ends. With the same 13 neurons, the bottom error is about one fifth of the top error. Training a neural network is partly learning where to put its kinks. That makes it more flexible than a fixed basis, such as polynomials or Fourier functions.
