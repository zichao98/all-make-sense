Kinks and boundaries are hyperplanes

Deep Learning Intuition · 22

Hyperplanes show up in three places. First, every neuron folds where w·x + b = 0. In 1D that set is a single point, the kink in our piecewise lines. In 2D it is a crease line; in d dimensions it is a (d − 1)-dimensional hyperplane. Second, inside each facet every neuron is fixed on or off, so the output is linear there. Its graph is a flat piece of a hyperplane one dimension up. A piecewise line is just those pieces glued together at the folds. Third, a classifier's last layer outputs the class from the sign of v·h + c, where h holds the hidden outputs. That is one straight cut, a hyperplane, in hidden space; a perceptron or linear SVM is the same cut with no folds before it. Pulled back to the input x, the cut bends: inside a facet h is linear in x, so the boundary is a straight segment, and it can only change direction where it crosses a crease. The animation really trains a one-layer ReLU network in your browser: 160 random points in a square, labeled by whether x₁² + x₂² is below 0.42, with 3, 6, then 12 neurons, full-batch Adam at learning rate 0.03 for 1,500 steps. In a node run of the same code, training accuracy reached 98% with 3 neurons and 100% with 6 and 12. That accuracy is on the training points only. More neurons give more creases, so the polygon gets more corners and hugs the circle more closely. In deeper networks, later layers' hyperplanes are bent by the earlier folds, so boundaries can turn many more times.
