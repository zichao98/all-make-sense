Deep Learning Intuition · 09

This really runs gradient descent in the browser. Each restart uses new random initial values, so each round differs. The theoretical best is the maximum error with perfectly placed kinks. You'll usually see the trained N = 13 network miss that ideal by several times. The ideal error for N = 40 is tiny, but training often can't reach it: the optimizer doesn't place the kinks precisely near the ends. That's why we usually allow some extra neurons in practice.
