# Playbook：內容、設計、版型與踩過的坑

## 1. 內容怎麼想

這系列簡報的目標是讓使用者對一個技術主題「有 sense」：看到一個新情況，能自己估出大概的答案。

**做法（以 `deep-learning-intuition` 為例）：**

1. **先把問題變成可以想像的幾何問題。** 「要幾個神經元」→「一條 ReLU 就是一個折角」→「要幾段折線才畫得像」。整份簡報都圍繞這個轉換。
2. **給一條能估算的公式，再給一個不用算的眼估法。** 例如 N ≈ B/√(8ε)，以及「數彎：1% 誤差時每個彎 6～10 個神經元」。
3. **用三個例子對比，其中一個是反直覺的。** x⁵、x²⁰ 都只要 13～14 個，同樣是五次的 T₅ 卻要 41 個 → 「看彎幾次，不是看次方」。
4. **理論之後一定接「真的跑跑看」。** 真實訓練常比理論差好幾倍，把這個落差講清楚。
5. **把使用者提到的其他概念連起來。** 例如傅立葉：先講結構上的對應（sin 神經元），再講各自的強項（吉布斯現象），最後講它如何反過來幫忙估神經元數（Barron）。
6. **最後一頁「一頁帶走」**：6 個重點，備註裡直接回答使用者最初的問題。

**章節結構（一份 20～25 頁的簡報）：**

| 段落 | 頁數 | 內容 |
|---|---|---|
| 封面 | 1 | 標題、副標、裝飾動畫 |
| 基本單位 | 2～3 | 最小的元件長什麼樣（附動畫） |
| 大字句 | 1 | 把難問題換成好想像的問題 |
| 估算 | 4～5 | 誤差法則、實算一例、公式＋表格、三例對比、真實訓練 |
| 進階（每個追問一段） | 各 3～6 | 章節分隔頁開頭 |
| 限制 | 1 | 這些直覺在哪裡會失效 |
| 總結 | 1 | 3×2 重點卡 |

**數字怎麼來：** 先寫一個 python 或 node 小腳本算出所有數字（例如對每個函數算彎曲預算、驗證用 13 個轉折點時誤差真的 ≤ 0.01、用 node 跑一次訓練確認會收斂），把結果貼進投影片。腳本放在工作目錄的暫存區即可，不用進 repo。

## 3. 版型與座標

畫布 1920×1080。內容頁一律：

```
section style="background:#F6F3EC;color:#17212B;font-family:…;padding:128px 128px 160px;display:flex;flex-direction:column;gap:24px"
  p  eyebrow：24px 粗體 letter-spacing:2px 橘色，格式「NN · 章節名」
  h2 標題：64px Noto Serif TC 700，line-height 1.15，一行
  …內容…
  p  頁尾：position:absolute;left:128px;bottom:64px;font-size:24px;color:#7A828C，「簡報名 · 頁碼」
  aside 講者備註
```

eyebrow + 標題結束在 y ≈ 262，內容從 y ≈ 294 開始，最多到 y = 920（有頁尾時）。

## 4. 排版估算（避免爆版）

這個格式不會自動縮字，排之前先算高度：

- 一行高度 ≈ 字級 × line-height（內文 28px × 1.5 = 42px）。
- **中文一個字 ≈ 1 個字級寬**，英數 ≈ 0.6 個字級。688px 寬的欄、28px 字 → 一行約 24 個中文字。
- 卡片高度 = 內容高度總和 + 上下 padding；不要寫死卡片高度。
- 標題 64px 時一行約 26 個中文字，超過會換行、把下面全部往下推。
- 加總：從 y=294 開始把每個區塊高度和 gap 加起來，必須 ≤ 920；超過就拆成兩頁，不要縮字。
- 公式 SVG 的寬高由 `tools/tex2svg.mjs` 印出；三張並排卡片每張內寬約 480px，三步驟卡片內寬約 429px。

## 5. 踩過的坑

- **`display:flex` 沒寫方向就是橫向。** 沒寫 `display` 的 div 才是直向。要並排一定寫 `display:flex;flex-direction:row`，要直排就不寫 display 或寫 `flex-direction:column`。
- **section 的寬高包含 padding**（border-box）。內容寬度是 1920 − 256 = 1664。
- **`<table>` 的儲存格只能放純文字。** 第一欄要放公式就改用 flex 列（見 `formula-table.html`）。
- **span 不能換字型或字級。** 所以內文裡夾一段公式時，要把那一行拆成 flex 列：`<p>文字</p><img 公式><p>文字</p>`。
- **二階導數寫 f″**（U+2033），不要寫 `f''`。
- **公式顏色要跟背景配：** 淺底 `#17212B`、橘卡 `#8A3E12`、深底 `#F0995E`。顏色是在 `formulas.txt` 裡指定的，同一個式子放在不同底色要產生兩個檔。
- **動畫的 JS 裡不要出現 `<` 和 `&`。** 用 `N>i` 代替 `i<N`、用巢狀 if 代替 `&&`。這是為了能原封不動搬回 Claude Slides（它的解析器較嚴格）。
- **動畫裡的字會跟著整頁縮小。** 在手機上整頁只剩約 0.2 倍，所以動畫字級至少 24px，重要文字放在投影片本體而不是動畫裡。
- **動畫初始值要穩。** 會除以零的參數（例如 −b/w 的 w）要避開 0；用 `Math.floor(t/週期)` 切換正負號。
- **真實訓練的動畫，先在 node 裡跑過同一段程式**，確認會收斂、記下典型誤差；有些隨機種子會讓神經元死掉，這是可以拿來講的現象，不是 bug。
- **頁碼與 eyebrow 編號是手寫的**，插入新頁後要把後面的全部更新。
